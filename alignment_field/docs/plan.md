# 对齐场验证：方法、数学、文献依据、评估方案

本文件在看到任何场的闭环结果之前写定（2026-11-05，北京时间）。之后若有改动，在文末"变更记录"里注明时间和原因。

## 0. 要回答的问题
在 Chongyu 的 `WMInsertionChargerRandomized-v2`（分支 `wminsertion`，提交 7a0abea，代码未改）上，一个按 SID 思路训练的对齐场，能否把分布外（OOD）的起始状态拉进分布内（ID），使固定的直推插入能够成功；在没见过的插座形状（四种轮流留一种）、没见过的握持俯仰角和握持位置下是否仍然成立。

## 1. 只用真机也拿得到的量
- 方法使用：手腕 RGB-D、相机内外参（真机上 = 正运动学 + 手眼标定）、关节角与由关节角得到的手位姿 H、插座几何规格（CAD）。
- 仿真真值的唯一用途：脚本专家完成"每个握持插一次"，对应真机上的人工遥操作插一次；专家内部用了什么真值不进入数据，只记录过程中的手位姿。
- 打分用插一次得到的 H_pre（同样只来自正运动学）。`tests/test_geometry_and_leaks.py` 检查方法代码（policy / perception / model / field）不访问任何仿真物体位姿。

## 2. 状态的定义（插座坐标系）
设插一次结束时手位姿为 H\*，插入行程中手的位移方向为 a（由正运动学测得）。
- 插座坐标轴：e_x = a（指向板内），e_z = 重力向上方向去掉沿 e_x 的分量后归一化，e_y = e_z × e_x，R_P = [e_x e_y e_z]。
- 插入前位姿：H_pre = H\* 沿 −e_x 退 (插脚长度 + 3 mm)，即插脚尖端在板外 3 mm。
- 状态：q = (t, r)，t = R_Pᵀ (p − p_pre)，r = Log(R_Pᵀ R R_preᵀ R_P)。
- 无量纲化：u = q / σ，σ = (1 mm ×3, 1° ×3)，使平移和转角可比（SID 距离中的 σ_p、σ_r）。
- 执行：场给出 Δu，手的目标位姿 = 以当前手位置为中心、在估计的插座坐标轴下平移 σ·Δu_t、转动 σ·Δu_r。执行时只需要当前手位姿和插座坐标轴，不需要 H_pre（测试见 `test_motion_matches_state_composition`）。

插座坐标轴在测试时由点云估计：板面 RANSAC 拟合（Fischler & Bolles 1981，排除法向接近竖直的桌面）得到 e_x，再与重力组合。探针实测与正运动学得到的轴相差 0.1°–0.6°。

## 3. ID 集合（SID 的"示范流形"）
对每个训练握持：在 H_pre 附近（横向 ±0.8 mm、各轴转角 ±1°、t_x = 0）随机取 32 个状态，各做一次固定直推（沿 e_x 推进 插脚长度+3 mm，5 mm/s；手落后指令 1.5 mm 判为卡住；手实际前进 ≥ 行程 − 1 mm 判为插入）。插入成功的状态构成 ID 集合
  M = { u_j }，只取训练形状、训练握持。
（SID 用示范起点附近的小扰动作为 ID；这里直接用"插入动作确实能成功"来定义，更严格。）

## 4. 感知：点云给 6D，RGB 给亚毫米
- 点云：深度反投影 → 相机外参到基座 → 用估计的插座轴、以手位置为原点表示 → 手前方 [−2, 12]×[−6, 6]×[−6, 6] cm 的盒内取 1024 点，附 RGB 颜色（DP3 的稀疏点云编码；SID、CFVS 以物体/孔为中心统一坐标）。
- RGB：原生分辨率 128×128 裁剪，覆盖插脚尖端和孔口所在区域。探针实测：孔偏移 5 mm 只改变尖端旁边 50–80 个像素，不能降采样（RVT-2 的"放大关键区域"）。
- 网络（`paf/model.py`）：
  - f_pc = PointNet(点)，u_pc = MLP(f_pc)：粗的 6D 状态；
  - f_rgb = ResNet18(裁剪, ImageNet 预训练)；
  - u_hat = u_pc + MLP([f_pc, f_rgb, u_pc])：亚毫米残差（CFVS 的先粗后细）；
  - p_ID = σ(MLP([f_pc, f_rgb]))：分布内置信度（SID 的 ID-confidence head）。
- 损失：SmoothL1(u_pc, u) + SmoothL1(u_hat, u) + 0.2·BCE(p_ID)；标签 u 由正运动学得到。

## 5. 场（`paf/field.py`）
能量（软最近邻；Back to the Manifold 的 −log 密度；h→0 时为 SID 的 ½·min_j‖u−u_j‖²）：

  E_h(u) = −h² · log( (1/|M|) Σ_j exp(−‖u − u_j‖² / (2h²)) )

场 = 负梯度（mean shift）：

  v(u) = −∇E_h(u) = Σ_j w_j(u) (u_j − u)，  w_j = softmax_j( −‖u − u_j‖² / (2h²) )

性质：远处指向最近的 ID 状态、长度等于到它们的距离；在 M 的模态处为零（进入分布后场自动关闭，同 SID）。h = 0.5σ。

执行步长（SID 的 η(d) 加截断）：Δu = v · min(1, s_max/‖v‖)，s_max = 3σ。

学习的场（SID 的 f_θ）：MLP(u) → v，在工作盒 |u| ≤ (15,10,10,8,8,8) 内均匀采样加 M 附近采样，回归 v(u)。只用 M，不看图像。闭环中运行的是它。

距离为什么不用 MMD：对单个当前状态，MMD² 化简为"常数 − 2 × 核密度"，与上面的 E_h 等价；MMD 两样本检验只用于评估终点分布（Gretton et al. 2012）。

## 6. 闭环
每次迭代：观测 → 估计 u_hat → 场 Δu → 执行；连续两次 ‖Δu‖ < 0.5σ 或满 25 次停止。安全限制（所有方法相同）：在方法自己估计的状态下，t_x 不超过 +1 mm。之后做与第 3 节相同的固定直推。

## 7. 划分（训练前定死）
- 形状：四种轮流留一种，训练只用另外三种（4 组）。
- 俯仰角（全范围 −60°～−20°）：内插测试 [−42, −38]，外推测试 [−60, −55]∪[−25, −20]，其余训练。
- 握持位置（全范围 −30～−10 mm）：内插测试 [−21, −19]，外推测试 [−30, −28]∪[−12, −10]，其余训练。
- 插孔偏移：环境默认的 ±20 mm 随机，不留出（由插座坐标系处理）。
- 测试种子与训练种子不重叠（训练 100000+，测试 900000+）。训练形状内部 10% 握持做验证集选模型；测试集不参与任何选择。

## 8. 评估
测试单元：每组形状划分 × {训练带, 俯仰内插, 俯仰外推, 位置内插, 位置外推, 两者都外推}。留出形状每单元 8 个握持，见过的形状每单元 4 个握持，每个握持 4 个 OOD 起点（|t_y|,|t_z| ∈ [3,10] mm，t_x ∈ [−15,−3] mm，各轴转角 ±6°）。所有方法用同一批起点：
- field：点云 + RGB 估计 + 场（主方法）
- field_pc：只用点云的估计 + 场（检验 RGB 的作用）
- oracle：真实状态 + 同一个场（排除感知误差的上限）
- none：不对齐，直接推（下限）

指标：直推插入率（Wilson 95% 区间）；终点是否落入 ID（到 M 最近距离 ≤ M 内部最近邻距离的 95% 分位）；终点到最近 ID 状态的平移/转角；终点与 M 的 MMD² 及置换检验 p 值（起点同样计算作对照）；field − none 的配对差（按握持自助法）。

通过标准（事先写定）：在没见过的形状上，field 的插入率比 none 高，且配对差 95% 区间不含 0；终点 MMD 检验相对起点明显下降。oracle 与 field 的差距单独报告，用来区分"场不行"还是"看不准"。

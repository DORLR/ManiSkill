# 结果记录（2026-11-05）

评估方式见 `docs/plan.md`。"插到底"= 场结束后固定直推，插入深度达到（插脚长度 + 3 mm − 1 mm）。起点离目标中位数约 13 mm / 5°。方法：
- oracle：真实偏差（关节角算出）+ 场，检验场本身；
- field：网络估计偏差（带色点云 + RGB 裁剪）+ 场；
- field_pc：只用带色点云那一支的估计 + 场（点云每个点带 RGB 颜色）；
- field_rgb：只用 RGB 裁剪，无深度；
- none：不对齐直接推。

## v1：A–D 四种形状，训练三种测一种（`results/summary.json`）
| 夹持条件 | oracle 见过/没见过形状 | field 见过/没见过 | none |
|---|---|---|---|
| 训练范围内 | 71% / 75% | 42% / 4% | 0% |
| 俯仰角内插 | 72% / 69% | 52% / 11% | 0% |
| 俯仰角外推 | 79% / 82% | 34% / 3% | 0% |
| 握持位置内插 | 78% / 75% | 55% / 2% | 0% |
| 握持位置外推 | 78% / 79% | 41% / 23% | 0% |
| 两者都外推 | 87% / 82% | 33% / 9% | 0% |

D 型 oracle 很低（约 11%）：它能插进去的窗口高度方向只有约 ±0.2 mm，手的定位误差可达 0.4 mm。

## v2：训练时每轮轮换一种形状不训练
离线误差与 v1 基本相同，未做闭环。

## RGB-only（`results/summary_rgb.json`）
见过形状：24–31%（俯仰角外推 7%，两者都外推 13%）；没见过形状：全部 0%。比带色点云 + RGB 差。

## v3：46 种程序化生成形状训练，A–D 全部只做测试（`results/summary_v3.json`）
oracle 69–81%（A 99%、B 85%、C 99%、D 5%）；field 0–8%；field_pc 1–8%；none 0%。
离线"目标附近"误差 0.59 mm 看似够用，但闭环出现"假到位"：停下时网络认为离目标约 0.8 mm，实际 3–9 mm。
只看"真实状态在目标附近时的误差"不足以预测闭环，必须同时看"网络说到了时是否真的到了"。

## 结论
1. 控制框架可行：给定准确状态，场在没见过的握法和形状上都能把分布外拉进直推能成功的区域（D 除外）。
2. 由于下游是直推，它能成功的区域基本就是几何对准点，场在这里退化为"移到目标点"；场相对简单控制器的价值尚未体现。
3. 端到端回归相对偏差是瓶颈：见过的形状上可用，握法变化（含外推）基本扛得住；没见过的形状上，即使用 46 种生成形状训练，仍会假到位。
4. 强深度噪声测试未完成（v3 无噪声已失败，停止以节省算力）。

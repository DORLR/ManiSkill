## Two measurements that changed the plan (23:20)

* Same state, different FM samples (`checks_v3g/imagination/*.branches.json`, 396 states x 4 continuations of
  16 s, v3g FM): 331 states all fail, 59 all succeed, 6 mixed (1.5 %). FM v4 so far (145 states): 116 / 27 / 2.
  A perfect selector over 4 FM samples would raise success by ~1 point.
* Spread of 16 FM v4 proposals at one state (`checks_v4/fm_spread.py`, 600 of the FM's own held-out states):
  commanded hand position after 0.4 s differs by 0.07-0.14 mm (the hand moves ~0.7 mm; hole clearance 0.5 mm
  per side; jams sit 0.6-2.4 mm off).
  -> selecting among FM proposals cannot help, however good the world model is (as in v1: 27 vs 28). The world
  model has to judge actions the policy does not propose (CEM), which needs (1) training data with the real
  consequences of such actions, (2) a score that separates actions when stuck, (3) affordable search.

## Decision with the user (23:30): a policy-independent world model

* The world model is to improve several algorithms, so its training data must not contain any policy's rollouts.
  The mixed run was stopped and deleted (runs/wm_v4_online, runs/success_v4_online, data/wm_v4_online); policy
  rollouts are used only to check the world model (the ood_val branch recording continues).
* Training data = demonstrations + policy-independent contact exploration (random contact states, truth-free random
  smooth actions, then a straight push). Success classifier label = "inserted within the next N s".
  CEM is used when a policy is improved with the world model, not when the world model is trained.

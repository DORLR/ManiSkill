## Closed loop (ood_val, 156 grasps x 2 starts, 12 grasps skipped because the expert cannot insert them)

| | train | pitch interp | pitch extrap | pos interp | pos extrap | combined | all |
|---|---|---|---|---|---|---|---|
| latent FM, 60 s | 20/50 | 15/40 | 16/52 | 18/50 | 18/50 | 11/46 | **98/288 = 34%** |
| latent FM, 24 s | | | | | | | 35/288 = 12% |

Median time to insert 27.4 s. Timeouts mostly stall at the hole face (median lateral 4.2 mm, angle
2.9 deg). Note: the 60 s limit was chosen after seeing the 24 s result (protocol changed post hoc).

FM + world model, test-time selection (16 FM candidates, WM predicts 0.8 s ahead, smallest decoded
distance to inserted executed; WM step 75k): stopped after 47 grasps; on the 41 comparable grasps
(82 episodes, shapes G105-G145) **27 vs 28 for FM alone** -- no difference. The FM is not changed by
this; selection can only help if a good candidate exists and the WM recognises it.

## Videos (user's desktop folder `videos_policy_v1`)

* `wm_guided_*`: 0.8 s predictions track the real latent (median 0.6 mm), but at the hole face all 16
  candidates are predicted alike (~20 mm left): nothing to choose from.
* `dream_*`: imagined rollouts from one real frame. They diverge from reality after ~4 s (gap 14-23 mm
  at 16 s). Later found (2026-11-08) that these used joints decoded from imagined latents, which
  explode within ~1.2 s; part of the divergence is that artefact, not only the WM.

## Offline checks (contact trials: offset 0-3 mm / 0-3 deg at 3 mm, straight push; train 2418 trials,
## ood_val 2429 trials of which 1723 jammed)

Will this push jam? (AUC, MLP probe, at push start): truth offset 0.98 (upper bound), latent + actions
0.87, joints + actions 0.79 (a grasp/shape prior: joints cannot regress the offset, R^2 < 0).

Offset regressed from the latent (R^2): lateral y 0.80, z 0.67, roll 0.43, pitch 0.74, yaw 0.61. From
the VAE pose head: pitch 0.02, yaw 0.19 -- the plug-point loss (mm on a ~20 mm plug) barely penalises
0.4 deg (~0.14 mm), so the pose head is angle-blind.

One-step prediction in jammed trials: real windows with < 0.2 mm progress 35%, WM 21%; progress per
0.4 s real 0.67 mm, WM 0.94 mm (inserted trials: both ~1.16 mm). The WM is optimistic in jams.
